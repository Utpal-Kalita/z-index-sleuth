01

The button is fine. The layer above it isn't.

A loading layer is meant to stop clicks while work is happening. In this example, it becomes invisible but keeps catching clicks. The button looks ready. Clicking it does nothing.

02

A fix is only half the answer.

Finding a likely fix is not enough. The same user action must work afterward, without weakening the test.

01 / Kane Test
Kane catches the failure

A real browser tries to generate a report with a normal click. Kane records a failure.

02 / DOM Probe
The DOM reveals the blocker

Five sampled points show that the invisible loading layer, not the button, receives the click.

03 / Gemini Source Fix
Gemini changes the source

The failure and DOM evidence go to Gemini. Its CSS change lets clicks through while the layer is inactive.

04 / Verification
Kane tests the same goal

The unchanged normal-click goal passes. A separate check confirms active loading still blocks clicks.

03

Same button. Same test. Different result.

Recorded on 17 November 2026. The inactive layer stops blocking the button; active loading still prevents clicks as intended.
